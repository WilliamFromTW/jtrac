### 關鍵要點速覽 / Quick Key Notes

1. **初始管理員帳密 / Initial Credentials**: `admin` / `admin`
2. **必填設定 / Critical Setting**: `jtrac.url.base`（例如 `http://192.168.1.100:8888/` 或 `https://issues.yourdomain.com/`，結尾必帶斜線 `/`），防止 Email 通知連結變成 `localhost`。
3. **預設語系 / Default Locale**: `locale.default`（例如台灣為 `zh_TW`，簡中為 `zh_CN`，日本語為 `ja`）。
